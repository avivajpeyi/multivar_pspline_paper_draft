With 7-day blocks and the same coarse-graining, the main change is

  Nb(30d)  = 4
  Nb(365d) = 52

so the 365d likelihood is weighted about

  52 / 4 = 13

times more strongly.



A simple 1-bin PSD example is

  LnL(S) = -c * log(S) - A / S + const

where

  c = Nb * Nh

and Nh is the coarse-bin merge factor.

At the optimum, the curvature in S is

  d^2 LnL / dS^2 = -c / S^2

so the local sharpness is proportional to

  c = Nb * Nh

Since Nh is basically the same in 30d and 365d, the sharpness scales mainly with Nb:

  sharpness(365d) / sharpness(30d) ~= 52 / 4 = 13

So with the same model dimension and same spline complexity, the 365d run has a much steeper LnL surface, which forces NUTS to use smaller step sizes and makes mixing harder.
